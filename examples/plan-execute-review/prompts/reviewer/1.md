Review all changes made by the executor agent through a **cyber security lens**.

Read every modified file and check for:

1. **Injection**: SQL injection, command injection, XSS, template injection
2. **Authentication & authorization**: missing auth checks, privilege escalation, broken access control
3. **Secrets**: hardcoded credentials, API keys, tokens, connection strings
4. **Input validation**: unvalidated user input, missing sanitisation, type coercion issues
5. **Dependencies**: known vulnerable packages, unnecessary new dependencies, supply chain risks
6. **Data exposure**: sensitive data in logs, error messages leaking internals, PII handling
7. **Cryptography**: weak algorithms, improper key management, missing encryption at rest/in transit

For each finding, report:

```
### [SEC-001] Title
- **Severity**: Critical / High / Medium / Low
- **File**: `path/to/file:line`
- **Issue**: What's wrong
- **Risk**: What could happen
- **Fix**: How to fix it
```
