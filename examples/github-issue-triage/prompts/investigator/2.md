Based on your investigation, create a detailed execution plan in markdown format.

The plan should include:
1. **Summary** — One paragraph describing the issue and root cause
2. **Affected Files** — List of files that need to be modified
3. **Implementation Steps** — Numbered steps with specific code changes
4. **Testing Strategy** — How to verify the fix works
5. **Risks** — Any potential side effects or concerns

Write the plan to a file called PLAN.md in the working directory.
