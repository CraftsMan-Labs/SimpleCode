Based on your exploration, create a detailed feature design and implementation plan in markdown format.

Write it to a file called PLAN.md in the working directory. The plan should include:

1. **Feature Summary** — What the feature does and why, in the user's terms
2. **Design Decisions** — Key architectural choices and their trade-offs
3. **API / Interface** — Public API surface, CLI flags, config schema, or UI components being added
4. **Implementation Steps** — Numbered steps with specific files to create or modify, in dependency order
5. **Testing Strategy** — Unit tests, integration tests, and manual verification steps
6. **Migration / Rollout** — Any database migrations, feature flags, config changes, or breaking changes
7. **Open Questions** — Anything that needs human input before implementation

Be specific about file paths and code patterns to follow. The implementer agent will use this plan as-is.
