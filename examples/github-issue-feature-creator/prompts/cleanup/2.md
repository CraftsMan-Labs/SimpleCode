Push the feature branch and create a draft pull request.

1. **Push** — Push the branch to the remote:
   ```
   git push -u origin <branch-name>
   ```

2. **Create a draft PR** — Use the `gh` CLI. Extract the repo and issue number from ISSUE.md. The PR should:
   - Reference the issue with `Closes #<issue-number>` in the body
   - Have a clear title following conventional commits: `feat: <description> (#<issue-number>)`
   - Include a well-structured body:

   ```
   gh pr create --draft --title "feat: <description> (#<issue-number>)" --body "$(cat <<'EOF'
   ## Summary
   <2-3 bullet points explaining what this PR does>

   ## Changes
   <List of key files changed and why>

   ## Test plan
   - [ ] All new tests pass
   - [ ] No regressions in existing tests
   - [ ] <any manual verification steps>

   Closes #<issue-number>
   EOF
   )"
   ```

3. **Clean up ISSUE.md** — Delete ISSUE.md from the working directory (do not commit the deletion, it's a local artifact).

Output the PR URL and a summary of what was committed and pushed.
