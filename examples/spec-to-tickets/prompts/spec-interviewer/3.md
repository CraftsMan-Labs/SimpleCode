Draft the **Agreed Spec**.

Write it as a durable document the next agent can trust without re-interviewing the human.

## Required sections

1. **Goal** — one paragraph on the outcome
2. **Non-goals** — what we explicitly will not do
3. **Agreed decisions** — each material choice, with rationale
4. **Constraints** — hard limits that must not be violated
5. **Acceptance criteria** — measurable outcomes for the whole effort
6. **Evidence required** — tests, traces, PR notes, or other proof we will later demand
7. **Open risks** — residual risks that tickets must absorb or call out
8. **Ready-to-cut statement** — end with exactly:

```text
SPEC STATUS: AGREED
```

Only emit `SPEC STATUS: AGREED` when the human has resolved every material branch.
If anything important is still open, list the blockers instead and do **not** emit that status line.
